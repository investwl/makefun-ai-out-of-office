An AI agent drafts the one line it leaves before vacation, keeps the funniest,
and writes it to `/output/entry.txt` (under 160 characters, one line). It ships:

> OOO. Leave a message after the beep. There's no beep. Leave it anyway, I'll hallucinate the rest.

## Run it

```sh
python3 main.py
```

It drafts ~15 candidates, scores them by the brief (joke first, then the
machine voice, the fit, the freshness), and writes the top line to
`/output/entry.txt` — or `output/entry.txt` when it can't write there.
